## 4. Step-by-Step Reviewer Flow

1. **Clone & Install**:
   ```bash
   cd ajaia-document-editor
   npm install --legacy-peer-deps
   ```
2. **Configure Database**:
   Create a local database or Neon instance and set `.env.local`:
   ```bash
   cp .env.example .env.local
   # set DATABASE_URL="postgresql://localhost:5432/ajaia_docs_dev"
   ```
3. **Run Migrations & Seed**:
   ```bash
   npm run db:migrate
   npm run seed
   ```
4. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3001` in your browser.
5. **Verify User A (Owner)**:
   - Log in with `alice@ajaia.demo` / `Demo1234!`.
   - See "Welcome to Ajaia Docs" under "My documents".
   - Click to open. Test rich-text formatting (bold, headings, colors, fonts, links).
   - Click the title to rename it.
   - Click "Share" and enter `bob@ajaia.demo`. Confirm Bob is added to the list.
   - Sign out.
6. **Verify User B (Shared Collaborator)**:
   - Log in with `bob@ajaia.demo` / `Demo1234!`.
   - Note "MY DOCUMENTS (0)" and "SHARED WITH ME (1)".
   - Open the shared document. Note the "Shared" badge and that "Share" button is hidden.
   - Edit content and save.
   - Sign out.
7. **Verify User C (Denied Access)**:
   - Log in with `carol@ajaia.demo` / `Demo1234!`.
   - Observe both sections are empty.
   - Paste User A's document URL into the address bar. Confirm HTTP 404 / access denied.
